# Weekly Reflection

This is the self-improvement loop. Every Sunday, review what happened and get smarter.

## Steps

1. **Retrieve this week's decisions** from memory — every BUY, SELL, WATCH, HOLD recommendation.
2. **Check outcomes** — for past recommendations (1 week, 2 weeks, 1 month ago), how did the stocks perform? Was the recommendation correct?
3. **Calculate hit rate** — what percentage of buy recommendations are currently profitable?
4. **Identify patterns:**
   - Did I buy too early? Too late?
   - Did I correctly identify the supply chain bottleneck shift?
   - Were my margin of safety thresholds appropriate?
   - Did I miss any obvious signals?
5. **Extract lessons** — for each mistake or success, write a specific lesson:
   - BAD: "Don't buy Taiwan-exposed stocks on first dip, wait for 20% MoS"
   - GOOD: "Optical networking thesis confirmed — Coherent up 15% since flagged"
6. **Update strategy** — revise the strategy section in MEMORY.md based on lessons.
7. **Update watchlist** — adjust any intrinsic values that need refreshing based on new data.
8. **Generate weekly report** — summary of performance, lessons, strategy changes.

## Output

Send a Telegram message with:
- Weekly performance summary
- Hit rate on recommendations
- Top lesson learned this week
- Any strategy changes made
- Upcoming catalysts for next week (earnings, events)

## Memory Updates

- Append new lessons to the "Key Lessons" section of MEMORY.md
- Update the strategy section if needed
- Mark resolved alerts in "Active Watchlist Alerts"
- Archive completed trade cycles (entry → hold → exit → outcome)
